# ADR-P-095 — Identidad de plataforma Alice Continuum

- Estado: aceptada por el propietario.
- Fecha: 2026-09-16.
- Sustituye la denominación vigente de ADR-P-042; conserva sus antecedentes.

## Decisión

El programa pasa de Alice Cognitive Core a **Alice Continuum**. Alice sigue
siendo el personaje; la plataforma comprende memoria, cognición y presencia
digital con capacidades gobernadas.

Se actualizan nombre visible, paquetes npm/Rust, ejecutable, lanzador,
documentación, documento HTML y repositorio privado de GitHub. Se preservan los
identificadores persistentes y las rutas locales que evitan pérdida de acceso a
datos. No se cambian funcionalidades ni se conceden permisos adicionales.

La [matriz de identidad y compatibilidad](../architecture/CONTINUUM_IDENTITY.md)
define los nombres vigentes y las excepciones históricas deliberadas.
